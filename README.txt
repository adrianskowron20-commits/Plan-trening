PLAN ADRIANA – home-screen app for iPhone

1. Put this whole folder on free HTTPS hosting.
   Easiest: open app.netlify.com/drop and drag the folder onto the page (free account).
   Alternative: GitHub Pages.
2. On the iPhone, open the address in Safari -> Share -> "Add to Home Screen".
3. Launch it from the icon. It opens full screen and works offline (at the gym with no signal too).

Data from the old HTML file does not carry over automatically:
in the old version tap Postep -> Eksportuj kopie, then in the new one -> Wczytaj kopie.

Updates: replace index.html and change VERSION in sw.js (e.g. plan-v2),
then open the app twice with internet access.
Your logged kg/reps stay on the phone; only the plan itself is on the hosting.
